# 戰力雷達｜汽車服務廠技師績效分析儀表板

依 2026 年各廠技師戰力分析資料建置的靜態儀表板（React + Chart.js，純前端，無需後端）。

涵蓋：綜合總覽、各廠績效、技師績效總表、技師個人分析、年資分析、維修里程分析、營收結構分析、績效推移、排名與異常、資料匯入（驗證預覽）、指標與門檻設定、使用者權限管理（主管／廠長／技師三種角色視角）。

資料範圍：1–8 月完整月份（9 月資料截至 9/15 尚不完整，已排除）。

## 本機預覽

直接用瀏覽器開啟 `index.html`，或啟動任一靜態伺服器：

```bash
python -m http.server 8080
```
